    Excel Format Guide

    The first row must contain column headers. Required columns:

    Column Required Description Accepted Values
    first_nameRequiredMember's first nameAny text
    last_nameRequiredMember's last nameAny text
    genderRequiredGendermale, female, other
    date_of_birthRequiredDate of birthYYYY-MM-DD or DD/MM/YYYY
    phoneRequiredPhone numberAny text
    addressRequiredResidential addressAny text

    Optional columns:

    Column Accepted Values
    emailValid email address
    occupationAny text
    marital_statussingle, married, divorced, widowed
    baptism_statuswater, holy_spirit, both, none
    baptism_dateYYYY-MM-DD or DD/MM/YYYY
    joining_dateYYYY-MM-DD or DD/MM/YYYY (defaults to today)
    emergency_contact_nameAny text
    emergency_contact_phoneAny text
    emergency_contact_relationAny text
    is_activeyes/true/1 or no/false/0 (defaults to yes)
    is_voteryes/true/1 or no/false/0
    voter_idAny text
    notesAny text

    Column headers are case-insensitive. Common variations like dob, phone number, first name are also recognized.
